# Vpliv prisluškovanja in šuma na varnost kvantnega protokola BB84

**Predmet:** Nekonvencionalne platforme in metode procesiranja (NPMP)  
**Univerza:** UL FRI

Seminarska naloga obravnava kvantno porazdelitev ključev s protokolom BB84 ter vpliv prisluškovanja in šuma na varnost izmenjave ključev. Cilj je proučiti spremembe deleža napak v izmenjanem ključu in možnosti zaznavanja prisluškovanja.
